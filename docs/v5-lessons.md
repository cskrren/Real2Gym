# v5：分层增强经验与验证范围

2026-09-14，本版把已完成的第三步整理为可迁移流程，保留v4人形约束及前两步八环节。本次实测对象是双FR3 + Franka Hand执行杯子放入微波炉、撤手、关门；不是人形增强或任意任务的验证。

## 实测结果

- 对杯子/微波炉尺寸、平面位置、水平朝向以及桌高进行了9个参数、18个方向的有限探测。近/远值和局部细化仅提供当前控制下的采样参考。
- 本轮 N=3、M=2：原场景加3个机械候选，各有原外观和2个外观候选，共12个原生通过。复用了两个既有成功组合，另一组合在三次缩幅后通过；这是筛选后的交付数，不是随机抽样12次的成功率。
- 实际N包含2或3项修改；流程允许1–3项，未要求这次交付必须包含单项，也未要求所有类别覆盖。
- 失败组合最初为微波炉横移−0.09m、旋转4°、等比尺寸0.75。每轮偏差乘0.85，三次后为−0.05527125m、2.4565°、0.84646875倍。前两次执行主要未通过末态稳定性，第二次缩幅还出现关门/几何失败，第三次缩幅通过；缩幅效果并不单调。
- 本次沿用2mm几何阈值，交付候选最大接触穿透约1.648mm，模型哈希一致，初态无大于2mm穿入。阈值、末态稳定指标、缩幅比例和预算均不是所有场景的默认常数。
- 12个候选各输出374帧原生轨迹/事件对齐视频、7个事件关键帧及首帧Blender样帧。视频完整解码并与9个导出MuJoCo图像核对帧身份；代表性视觉复核为每个候选0/135/360帧，未声称逐一人工复核全部关键帧。
- 完整背景候选本次随机均抽到Pawn Shop；纹理、干扰物位姿及灯光参数另有变化。不能把资产候选列表解释为本次已覆盖所有背景类型。源数据、模型和渲染不随技能仓库发布。

## 改进决定

1. N允许单项，不增加跨类别覆盖配额；失败后保留同组合小幅缩减，记录每一轮，不无限逼近原场景凑数量。
2. 物体/设施共享增强能力，支撑桌尺寸为派生约束；安装关系决定机器人是否随桌升降，不能推广桌面机械臂逻辑到人形。
3. 外观变体来自已通过父场景，但新增干扰物可能影响物理，因此仍复验；通过、渲染完成、有效场景数分开报告。
4. Blender append后更新依赖图再读取世界变换。本次干扰物显示错位经此修复，并以两边包围盒和投影验证；物理轨迹不因显示修复而无记录更改。
5. 共享重复纹理、复用静态缓存，比反复下载/建模省时。16GB本机的完整背景曾因GPU内存压力变慢，恢复CPU并使用静态缓存；这不是CPU普遍更快的结论。
6. 场景脚本依赖专用关节/对象命名和判据，不直接包装成通用工具；发布流程和适用边界，减少新场景误用。

详细执行和记录项集中在[第三步参考](../skills/real2sim-prompt/references/augmentation.md)，避免在主入口重复加载案例日志。后续需验证更多任务、背景和硬件，并按用途明确几何/稳定性指标；本次通过不证明真机安全或所有参数区间可行。
