# v4：人形重定向经验与适用边界

本版整理 G1 + Dex3-1、H1-2 + 仓库原装五指手的操作任务经验，保留 v3.3 的两步八环节。案例只支持流程设计，不证明所有人形/手组合或自由站立任务可行。

## 主要修正

1. **源动作优先**：先在原位置尝试原轨迹和接触点；无法执行后才进入保持原逻辑的替代规划。两阶段都要求避免危险、高难和不稳定接触动作。
2. **A/B 同等比较**：原位置＋新轨迹，与小幅移位＋尽量原轨迹都要考虑；站位与轨迹是同等重要的保真目标。历史已经移动过的机器人站位不能重命名为“原站位”。
3. **接触与姿态分开诊断**：推门有接触力也可能方向不对，导致门反向运动或停滞；不能仅凭接触失败把姿态定为危险。优先减少非预期断触，检查法向、实际指垫、非作用手指、阶段切换和撤离。
4. **连续运动优于孤立 IK**：多起点 IK 在各帧位置误差很低，仍可能出现关节分支跳变。连续参考、邻姿态约束及平滑控制切换能改善运动；适用参数需按新任务验证。
5. **物理任务与保真度独立**：有效替代轨迹经完整原生执行通过，标为 `success_adapted_trajectory`；改动与时间映射显式展示，不能宣称精确复现人手。
6. **交付实际速度**：源视频事件对齐会压缩较慢执行，应同时展示原生速度视频，观察停顿、冲击和反复试探；三方视频由同一次原生状态驱动。

## 本次案例证据，不作为通用参数

G1 候选 A137 保留原人站位，改变了门接触区域，完整执行抓杯、放入、撤手和关门，原生时长约41.09秒；七个关键帧复核、374帧三方输出及视频解码/身份检查完成。关门移动区采样接触覆盖约81.3%，最长断触约50ms，门接触峰值约5.40N。该历史结果按当时用户接受范围通过；这些数值不是 v4 的通用容差或新场景自动通过标准。v4 按最新要求优先减少断触，不保留“短暂断触不单独判失败”的规则。

B 分支的小幅移位外缘接触候选出现接触获取失败；静态拟合小残差没有保证原生关门成功。这支持“几何筛选后仍需物理诊断”，不证明原接触点绝对不可达。历史 C 同时改过站位与接触，不能算 A。H1-2 自带五指手的既有结果独立保留，不能冒称 Dex5-1 任务结果。

固定骨盆和机器人重力补偿只验证相应仿真条件；没有据此验证自由站立、步行或真机安全。初始站位调整和执行中移动分别记录。场景数据与专用控制脚本不随此仓库发布。

## 减少无效计算

- 共用源视频、首帧几何、核心背景、相机和真实事件；换硬件只重做受影响资产、运动与物理。
- 小范围有假设的候选 → 无渲染短诊断 → 受影响关键帧复核 → 最终完整回归 → 一次精细视频渲染。
- 记录实际生效参数与入口哈希；参数替换未生效的重复运行不作为独立方案。
- 看图用于空间歧义和自然程度，数值脚本用于全步极值、接触区间及输出一致性；不重复阅读大日志或为未变化背景重写五问。
- 将人形规则放在按需参考，案例经验与通用要求分开，主入口保留路由和关键顺序。
