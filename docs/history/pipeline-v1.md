# Real2Sim v1：整体流程

本次将原有两步流程、外观补全和最多 5 轮闭环整理为统一的 **v1**。这是整合版，不丢弃原有能力：URDF 结构、全部真实视角、同源帧对齐、全场景审计、逐帧五问、异常前后检查、MuJoCo 接触校准与独立物理验收均保留。

## 从输入到交付

|阶段|执行内容|进入下一阶段的依据|
|0. 输入与边界|区分续做和从头开始；核对真实视频、视角、源帧及时间来源|真实与模拟、实测与拟合分开；fresh_start 不携带旧模型和结论|
|1. 真实事件发现|全片浏览/候选扫描，逐帧确认新接触、分离、抓持、支撑转移、进入/离开等关系变化|事件表包含对象、变化前后、时间区间、全部可用视角和不确定性|
|2. Blender 场景与动作|URDF/机械链、相机和尺度拟合、物体与容器空腔、动作、材质纹理灯光背景|全场景结构、初始支撑、碰撞及运动筛查完成|
|3. 第一步事件复核|事件前、发生时、事件后逐检查帧×视角五问，异常向前后扩查|同帧相机与相对位置优先；达到约定视觉/几何质量|
|4. MuJoCo 迁移与执行|保留显示/碰撞映射；核对结构和初态；静置与分阶段执行；对准→闭合→双侧接触→力和摩擦|区分模型加载、状态回放、接触测试和原生任务结果|
|5. 第二步联合复核|模拟逐步检测事件，与真实事件和异常窗口取并集；重查五问和物理判据|完整相关物理步检查、事件匹配/遗漏、碰撞、承载、滑移、任务和末态稳定分别有证据|
|6. 回归与交付|从最终磁盘配置完整回归；原生轨迹回传 Blender，补齐外观并重开工程验证|输出全部视角的同源 real/sim 关键帧；视频按需，完整解码核验|

完整相关回归出现新问题时返回修正闭环，不因已经开始渲染而忽略。只请求第一步时在对应范围交付，未执行的物理力学检查明确标为未评测。

## Key frame 的新定义

关键帧是**对象关系变化的证据**。每个事件选 `before / onset（或不确定区间）/ after`，事件邻域按稳定边界自适应扩展。仓库参考图、等间隔抽帧和首末帧仍可辅助观察，但不能替代事件发现或计入事件覆盖分母。

真实与模拟的首触时间分别记录。两者错时就检查两个邻域中各自同源时间的 real/sim，不把不同时刻拼成“同帧一致”。事件集还包括意外碰撞、滑脱与新增接触，修正后重新检测受影响部分。

## 五问与物理判定如何配合

五问对每个已选检查帧、每个可用视角回答：最大差异、相机是否对齐、物体相对位置是否一致、是否穿模/接触异常、逼真度是否满足用途。问题帧向前后扩查，新加入的检查帧同样保留五问。首次未检查的帧不能继承邻帧结论；共享数值证据和已验证相机依赖可以引用。

物理检查独立记录结构、初态、接触距离与力、对准/闭合、双侧承载和滑移、穿入/隧穿、实际力矩、支撑/整体包含、任务结果、平移与转动稳定以及求解器状态。采用按任务尺度预先记录的容差；正常软接触不因微小非零深度就否决，超限和缺失检查也不能靠画面认可通过。详细定义见[事件与复核规范](../../skills/real2sim-prompt/references/events-and-review.md)。

## 共享的修正闭环

**发现阻塞 → 定位主要原因 → 修改一个候选 → 检查事件前后 → 重新检测受影响事件 → 五问与物理回归。**

每场景两步共用最多 5 轮。初始基线为第 0 轮；不同修改候选开始验证即计一轮，批量候选也分别计数。通过提前停止；达限交付最佳候选与未解决问题，不宣称成功。续做、换问题或换阶段均不重置轮数。完整相关回归属于必要验证，不能省成一张关键帧。

## 速度与 tokens

- 全片候选扫描和逐物理步统计由工具完成，模型只看多视角事件总览、歧义区域和失败摘要。低成本扫描不等于降低事件覆盖要求。
- 每张帧图只存一次，多事件引用；五问首次具体填写，依赖未变时增量复用。报告由同一结构化记录生成。
- 先局部、无渲染验证假设，再完整回归，最后精细渲染；仅修改材质时不重跑物理，修改容器/轨迹时必须让关联物料与事件缓存失效。
- 容差按用途提前设定，保留用户接受的非阻塞偏差。避免无限抠背景，同时不将未完成的材质纹理补全当作最终高质量画面。

## 从头开始的边界

新输入目录只含真实视频、裁剪/压缩来源、源索引/时间说明和当前技能。旧 Blender、MJCF、动作/拟合结果、参考帧列表、旧评测均排除；历史审计保留在输入范围外。

目录隔离不能擦除当前对话。若要检验真正不携带旧对话的执行，应让独立会话只从输入目录开始。本次整理与输入准备本身不等于四场景已经重新跑完。
