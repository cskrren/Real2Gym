# Example requests

These are editable prompts for an agent with the complete Real2Gym skill installed. They are **not precomputed results or executable configuration files**. Replace absolute-path placeholders before use.

- [Robot demonstration](requests/robot.md): same-hardware reconstruction and execution.
- [Human demonstration](requests/human.md): hardware selection and retargeting.
- [Accepted-scene augmentation](requests/augmentation.md): mechanical parents and appearance children.

Prepare external dependencies first; see [getting started](../docs/guides/getting-started.md). The synthetic fixtures under `tests/` exercise validators only and must not be presented as successful physical tasks.
