# 第二步：Blender → MuJoCo

已有接受的静态 `.blend` 时，先按[动作恢复与第二步衔接](motion-execution.md)核对是否有源动作/状态。静态工程没有轨迹时先生成事件与运动目标；已有有效轨迹才直接开始迁移。导入、接触测试、任务完成和几何验收分别记录；第一步的视觉认可不证明物理成功。只在运行慢、接触密集或需要优化时读[性能与增量执行](mujoco-performance.md)；创建交付记录时读[输出约定](output-contract.md)。

## 1. 固定输入，先做小型性能检查

只读当前清单、接受范围、机器人描述、实际渲染相机、时间戳和必要配置；不从历史脚本重新推理整个场景。保留原 `.blend`，建立独立迁移目录。

导出求值网格、刚体局部变换、初态和源索引。分别处理 parent inverse、缩放和 mesh origin。程序材质无法等价迁移时登记外观差异，不为截图效果改写相机或实测运动。

模型编译后，先在初始化及接触密集阶段测少量物理步的实际耗时、接触数和警告。估算完整候选成本再开长跑；静置很快不代表抓持/倾倒很快。性能异常时先读性能参考，不盲目启动多个全程候选。

## 2. 转移结构与可碰撞空腔

- 由 URDF/等效描述保留 joint origin、axis、range、惯量和 visual/collision origin。缺失工具惯量可估计并记录；负 mimic 与正范围矛盾时核对关系后修正，保留原值和理由。
- 末端、夹爪与腕部相机保持机械链；独立 EE 轨迹先与关节 FK 比较，不能断开机械链来匹配画面。杯沿夹持使用杯沿接触参考点，不要求杯中心与夹爪中点重合。
- 显示网格与碰撞代理分开，以稳定对象ID和局部变换关联；Blender 保留高质量材质/纹理/背景，MuJoCo 碰撞几何按物理用途简化。常规网格凸碰撞不能跨越杯/碗空腔；用足够精度的凸分段或经当前版本验证的表示。检查容器内部、底壁接缝和粒子尺度。
- 目标物、物料具有物理自由度；固定支撑按用途固定。显式记录质量、惯量、摩擦、重力、时间步、增益、力矩限制及来源：实测、资产标称、估计或校准。
- 初始 keyframe 必须显式加载。装配排除对有记录；不关闭手指—目标、目标—容器接触来制造成功。

用源状态做运动学诊断回放，核对全部源帧的机器人、物体和相机变换。低转换误差只证明与 Blender 一致，不证明真实世界精度。模型/相机未变时复用该基线。

## 3. 分阶段跑真实物理

采用[事件与物理判定](events-and-review.md)中的对象关系、事件邻域和覆盖门槛。模拟事件从实际每步接触/状态提取；不以既有参考帧代替首触、分离及意外交互扫描。

先做静置、支撑和任务相关隔离测试，再推进接近、首触、稳定抓持、搬运/倾倒、释放和落定。候选运行到足以区分当前方案的事件与后续稳定边界即可；明显滑脱或物料全部错过目标时保存失败窗口，不继续长时间空跑。

原生执行通过驱动器推进。初始化后不得重置目标物 qpos、添加抓持 weld/父子附着或落点引导，冒充接触完成。辅助执行若属于任务范围，单列模式与约束。

有可靠关节轨迹时优先原生关节控制；只有末端目标时再选择 IK/末端控制。Mink 不是必需依赖。按实际时间戳插值，视频播放 fps 单列；速度前馈和限幅关系有记录。实测轨迹不覆盖，必要调整保存为有来源的修正版。

## 4. 按证据校准，局部失败局部诊断

接触面选错、释放后翻转或距离指标异常时，按[接触与交付排查](contact-and-delivery.md)定位实际碰撞对，区分局部诊断与最终回归证据。

遵守主入口的持续修正闭环；本步沿用累计轮次，不设上限。初始物料穿入、帧间短暂超限和最终旋转未稳定都是待修正项；任务部分完成或可视化完成不能作为提前停止理由。有可执行方案时继续定位、修改和前后检查；仅实际阻塞或用户停止时交付未通过结果。

|优先级|检查|修正方向|
|---|---|---|
|对准|安装、接触位置/朝向、visual/collision 重合、目标姿态|先定位几何与参考点误差；杯沿夹持不同于物体中心夹持|
|闭合|命令/实际角度、开口与被夹厚度、mimic、限幅|少量平滑闭合候选，保持释放语义|
|双侧承载|两侧各自接触力、持续时长、相对工具滑移|区分首触、接触过渡和持续持物；按事件前后逐物理步检查|
|力与摩擦|指面力分布、实际电机力矩、滑移、冲击|双侧接触建立后再调增益、阻尼、力矩与摩擦；不靠极大参数补偿错位|

实际力取自物理求解，不能只看 contact 开关或距离；margin 内小正间距也可能承载。力与姿态使用同一物理时刻，区分积分前接触和积分后 qpos。承载阈值按目标/机构定义，不把某次 0.05 N 当通用标准。

支撑判断按物体—支撑面聚合有效接触力，必要时投影到重力方向；不能要求每个小接触点都超过同一承载阈值。多点分担重力可能使逐点判断全是假阴性。夹爪两侧仍分别聚合，不能相加掩盖单侧缺失。

瞬时波动可带说明通过，但保留实际占比、力峰、过渡帧和稳定边界。搬运窗口的 100% 不代表首触至松开全程 100%。五问复用未失效的视觉基线，更新物理运动影响的项；新事件补关键帧，不把邻帧结论复制成未检查帧的观察。

### 有假设的小型校准试验

- 每个试验记录现象、待检验假设、修改变量、合理范围、预期改善、实测结果和接受/拒绝理由。先分辨几何/时序、闭合命令/实测开口和控制响应，再调质量或摩擦；位置控制与力矩控制按机构选择，不直接套其他场景的增益。
- 默认用少量受控单变量试验区分原因；确需联合拟合时记录耦合变量，不把共同改变的结果归因于单项。以轨迹、滑移、双侧力、事件时间和结果联合判断，二元成功不足以辨识物理参数；没有测量就不构造力/力矩拟合真值。
- 候选优先从修改后的模型重新编译、初始化；若修改已编译的质量/惯量等参数，按当前 MuJoCo 版本刷新派生常量并验证实际生效值。记录实际接触对的摩擦与求解配置，不能只看单个 geom 的输入值；渲染材质与接触材料不是同一套参数。
- 校准用于减少观察误差；扰动试验用于检查敏感性，两者分开统计。弱响应无法区分参数时保留范围/不确定性；卡扣、柔性夹具等缺失结构不能用极高摩擦伪装。保留失败基线，不要求每场景固定跑参数网格。

## 5. 独立验收，再渲染一次

候选确定后，从磁盘最终模型、控制和初态运行完整回归。至少分别输出：

|结果|依据|
|---|---|
|模型导入 / 运动学转移|原生编译、结构、同源变换与相机|
|基础接触|静置、支撑、落入容器等隔离测试|
|任务完成|持续抓持、抬升、运输/倾倒、释放、整体到达目标、预期支撑与最终速度|
|几何与数值|既定穿入容差、检查步数/区间、警告、有限状态|

**`task_success=true` 不能替代几何验收。** 总体状态同时考虑本轮要求的各项；超出既定容差仍是未解决项，不事后扩大阈值。中心入容器不足以证明整体进入，按形状检查边界/角点；模拟物料数量与真实可见数量的来源分开。

达到当前用途后停止。扰动测试只在对当前不确定性有价值或用户要求时做，单列实际配置与分母；不为所有场景固定增加一批全程测试。

交付 `scene.xml + assets + 初态/控制入口`，模型、资产、控制和 rollout 哈希绑定。macOS viewer 使用当前环境支持的启动方式（如 mjpython），显式 reset 初态。最终视觉交付将本次原生状态回传原 Blender 显示场景，保留材质、纹理、灯光和背景；按[外观与物理轨迹渲染](rendering.md)检查映射、相机、时间和可编辑工程的重开结果。MuJoCo 基础画面用于诊断，不能替代已要求的精细 real/sim 对照。按用户需要导出全部可用视角；完整解码检查数量/尺寸/时长，抽查首末和交互帧。源外稳定时段单列，不伪装成真实对应帧。

保留失败版本及其实际资产，不能让旧 XML 指向已经覆盖的碰撞网格。报告、页面与五问表从同一评测记录生成；未检查的结果标 `not_evaluated`，不可由脚本退出码或画面认可补成通过。
